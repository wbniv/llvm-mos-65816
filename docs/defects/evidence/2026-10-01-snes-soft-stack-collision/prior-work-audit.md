## Assessment

- **Source:** no compiler patch or live-source change covers this. The trigger is upstream behaviour (the `-O3` inliner threshold and `MOSNonReentrant`'s conservative recursion analysis), and the missing guard is in our SNES platform linker script.
- **Binary:** the installed toolchain reproduces the report's ROM hashes byte for byte. Upstream `llc` on the same `-O3` IR and an end-to-end build with the unpatched upstream clang fail the same way, so no downstream patch is involved.
- **Decision:** this is a new canonical record. It is distinct from `mos-native-width-pressure-sets`, which only recorded the sighting and whose pressure-set change is not involved: all four `llc` variants and the plain `mosw65816` build fail. It is also distinct from `reentrant-attribute-contract`, which is about the frontend attribute contract, not a resource overlap. The rdiff fix `e3bb5a62` is an earlier, unrecorded sighting of the same platform mechanism, which this record now covers.
