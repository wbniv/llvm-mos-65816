  committer date:
  `for f in docs/plans/*.md; do git log --follow --format='%h %cI' -- "$f" | tail -1; done | sort -k2`.
- **Commit(s)** = the full `git log --follow` set for each plan file, oldest → newest — every commit that
  created or revised it (plan authoring, implementation, status updates, deferral triage). Links point at
  `github.com/wbniv/llvm-mos-65816/commit/<sha>` (private repo — clickable for the owner while authenticated).
- **Summaries / categories** are hand-authored from each plan's TL;DR / status header; they are *not*
  auto-generated, so update this table by hand when a plan is added or its disposition changes.
