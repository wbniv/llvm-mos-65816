## What's already done (#320)

Far-pointer codegen for **static/compile-time addresses** is complete and two-emulator verified:

- Address-space layout: `AS0=16-bit` (6502 default, unchanged), `AS1=8-bit ZP`, `AS2=32-bit far`
  (24-bit address in low 3 bytes, 32-bit storage, opt-in — NOT the new default). AS3/AS4 deferred.
- `LDAbsLong` / `STAbsLong` pseudos → `LDA_AbsoluteLong` / `STA_AbsoluteLong` MC instructions.
- `G_LOAD_FAR_ABS` / `G_STORE_FAR_ABS` GISel pseudos; `tryFarAbsoluteAddressing` legalizer.
- Cross-bank read verified: `lda $018000` from bank $01 round-trips on both MAME and bsnes-jg.

**Runtime far pointers** (pointer value computed at runtime, not a link-time constant) are not yet
implemented. A non-constant AS2 pointer currently **fails to legalize loudly** (deliberate). That's
what this task adds.

## What to implement

Three sub-items; implement in this order:

### First: check 3c and 3b (may be free)

**3c — far-pointer arithmetic (`G_PTR_ADD` on AS2):** write `examples/65816/far_arith.c` (see plan
§3c), compile, check disasm. If the 32-bit add already legalizes correctly, 3c needs no code — just
the test. If not, add an explicit `G_PTR_ADD` legalization for `LLT::pointer(2, 32)` in
`MOSLegalizerInfo.cpp`.

**3b — near→far cast (`G_ADDRSPACE_CAST` AS0→AS2):** write `examples/65816/far_cast.c` (see plan
§3b), compile. If it zero-extends naturally (16-bit pointer → 32-bit far, bank=$00), no code needed.
If not, add the explicit legalizer case.

### Then: implement 3a (the real work)

**3a — `lda [dp]` / `sta [dp]` (runtime far-pointer dereference via indirect-long):**

The 65816 `lda [dp]` (opcode `$A7`) reads a 24-bit address from 3 consecutive ZP bytes at `dp`,
`dp+1`, `dp+2` (little-endian: low, high, bank). A 32-bit AS2 far pointer stored in 4 consecutive
ZP bytes — `{lo, hi, bank, pad}` — gives those 3 bytes at the first byte's ZP address with no
byte-swapping.

**Files to touch (all under `vendor/llvm-mos/llvm/lib/Target/MOS/`):**

1. **`MOSRegisterInfo.td`** — add `Imag32` register class: 4 consecutive ZP bytes (parallel to
   `Imag16`). Use the `__rs*` range, not `__rc*`. Find `Imag16` entries for the template.

2. **`MOSInstrInfo.td`** — add `LDA_IndirectLong` / `STA_IndirectLong` MC instruction defs inside
   the `let Predicates = [HasW65816]` block (around line 751). The `IndirectLong` addressing mode
   already exists (`MOSInstrFormats.td`); these are the missing LDA/STA forms:
   ```
   def LDA_IndirectLong : Inst16<"lda", Opcode<0xA7>, IndirectLong>;  // lda [dp]
   def STA_IndirectLong : Inst16<"sta", Opcode<0x87>, IndirectLong>;  // sta [dp]
   ```

3. **`MOSInstrLogical.td`** — add `LDIndirLong` / `STIndirLong` logical pseudos (near `LDAbsLong` /
   `STAbsLong` at ~line 558 for the template), expanding to the new MC instructions and taking
   `Imag32` as the ZP address operand.

4. **`MOSInstrGISel.td`** — add `G_LOAD_FAR_INDIR` / `G_STORE_FAR_INDIR` GISel pseudos. Use
   `G_LOAD_FAR_ABS` / `G_STORE_FAR_ABS` (around line 83/161) as the template.

5. **`MOSLegalizerInfo.cpp`** — extend the `case 32:` block (around line 2267):
   - After `tryFarAbsoluteAddressing` returns false, call a new `tryFarIndirectAddressing` that:
     - Creates an `Imag32` virtual register
     - Emits stores to write the 32-bit far pointer value into the 4 `Imag32` ZP bytes
     - Replaces `G_LOAD`/`G_STORE` with `G_LOAD_FAR_INDIR`/`G_STORE_FAR_INDIR` taking the `Imag32`

6. **`MOSLegalizerInfo.h`** — declare `tryFarIndirectAddressing`.

7. **`MOSInstructionSelector.cpp`** — add `G_LOAD_FAR_INDIR → MOS::LDIndirLong` / `G_STORE_FAR_INDIR
   → MOS::STIndirLong` in the load/store opcode switch (alongside `G_LOAD_FAR_ABS` at line 3139).

## The 65816 far-pointer target to hit

```c
// examples/65816/far_indir.c
// Runtime far-pointer dereference — must emit lda [dp] (opcode $A7), not lda $018000.
#include <stdint.h>
__attribute__((noinline))
__attribute__((address_space(2))) volatile uint8_t *make_far_ptr(uint32_t a) {
    return (__attribute__((address_space(2))) volatile uint8_t *)a;
}
static const uint8_t rom_sentinel __attribute__((section(".rodata.bank1"))) = 0xF3;
int main(void) {
    uint32_t addr = (1UL << 16) | (uint16_t)&rom_sentinel;
    return *make_far_ptr(addr) == 0xF3 ? 0 : 1;
}
```

Expected disasm gate: opcode `a7 XX` (`lda [dp]`) present; no `af XX XX XX` (`lda $...long`).  
Expected execution: exit 0 on both MAME and bsnes-jg.
