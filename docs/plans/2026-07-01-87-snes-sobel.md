## Context

A signed 3×3 **Sobel** edge detector: `Gx`/`Gy` are signed multiply-accumulates over a 3×3
window, and the edge magnitude `|Gx| +sat |Gy|` uses **saturating** arithmetic via
`__builtin_elementwise_add_sat` (→ `G_SADDSAT`) and `__builtin_elementwise_sub_sat`
(→ `G_USUBSAT`). Distinct from **#57 medfilt**, which is a min/max compare-exchange sorting
network (no MAC, no saturation). On the host oracle (gcc, no such builtins) a bit-identical
manual fallback keeps the differential meaningful; the **target** (clang) exercises the
saturating-intrinsic path.

## Algorithm

```
src(x,y,phase): procedural ring+diagonal step pattern, values ~[-120,120]
Gx = (s02-s00) + 2*(s12-s10) + (s22-s20)     # signed MAC
Gy = (s20-s00) + 2*(s21-s01) + (s22-s02)
mag = add_sat(|Gx|, |Gy|)                     # G_SADDSAT (clamps, no wrap)
m8  = clamp(mag>>1, 255)
out = sub_sat_u8(m8, 16)                       # G_USUBSAT (floor without underflow)
GATE_N phases; fold every edge magnitude over the 30×30 interior.
```
