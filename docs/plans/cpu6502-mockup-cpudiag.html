#102 cpu6502 — Variant B: CPU Block Diagram

Internal 6502 datapath — active blocks + wires light yellow for each instruction · Waldo disasm in top half · 3× scale (384×384)

This variant shows the 6502's internal datapath as a block diagram: PC, FETCH/DECODE, ALU (with gate type inside), accumulator, X/Y registers, flags, address bus, and data bus. For each instruction the active blocks and data-flow arrows light yellow. Top half: Waldo 16×16 disassembly listing (pixel-accurate). Bottom half: Canvas 2D schematic. This is an alternative to the "8 gate symbols" panel in the first variant.
