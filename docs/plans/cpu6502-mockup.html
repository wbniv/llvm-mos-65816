#102 cpu6502 — 6502/65C02 CPU Disassembler + Simulator

Pixel-accurate mockup · 512×512 (128×128 SNES canvas @ 4×) · Waldo font16 disasm · electronic gate symbols · SNES 2bpp palette

Top half (SNES canvas y=0–63): 4-line disassembly listing rendered pixel-by-pixel with the recovered 16×16 Waldo font (face = bright yellow on current; dim on context lines). Bottom half (y=64–127): 8 traditional electronic gate symbols — AND, OR, XOR drawn with their classic schematic shapes; ADD (full adder), SUB, SHL, SHR, CMP as labelled blocks. Active gate filled yellow; all others dim. Register strip at the bottom.
