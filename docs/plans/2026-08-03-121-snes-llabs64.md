# #121 — Seismograph Absolute Trace (`llabs64`)

**Status:** DONE + PUBLISHED 2026-08-03 — clean positive. Round 7 compiler-probe ROM.

## Question and shape

Can the target lower both `llabs()` and the canonical `x < 0 ? -x : x` idiom for signed 64-bit
values? The sample set crosses the 16-, 32-, and 48-bit limb boundaries and includes
`INT64_MIN+1`; `INT64_MIN` is deliberately excluded because its negation is undefined in C.
Both results and the input are folded into a deterministic CRC over 128 steps.

The visual proof is a dual-trace seismograph. Gold signed samples cross a blue zero line, while
the cyan rectified magnitude mirrors above and below it. The tallest legal pulse is
`INT64_MIN+1`, and every plotted point comes from the tested kernel.

## Gates and published result

- Host oracle: `0x8490`.
- LLVM IR contains the signed i64 absolute-value operation.
- The honest non-LTO object build passes `-verify-machineinstrs`.
- Host == default == a16 == xy16 == `0x8490` on MAME and bsnes-jg after 480 frames/ticks.

Run with `dev/run.sh llabs64`.
