LZSS Gallery caption layout

Three 256×224 layout proofs. The final ROM uses HDMA to run Mode 7 above the dashed line and Mode 1 below it, with the repository’s real Waldo-16 and font8 bitmaps on BG2/BG3. Browser fonts below only demonstrate measured rows, margins, hierarchy, and transition behavior. The split moves because only the caption rows actually used are reserved.
