## Context

An **IMA-ADPCM** decoder whose predictor is updated with **saturating** add/sub
(`__builtin_elementwise_add_sat`/`_sub_sat` → `G_SADDSAT`/`G_SSUBSAT`) inside a **serial
feedback loop** — each output sample depends on the previous predictor, and the step size
walks an 89-entry LUT indexed by a running state. Distinct from **#48 IIR** (wrapping
fixed-point feedback, no saturation) and **#67 huffman** (no feedback). Host gcc uses a
bit-identical manual saturating fallback; the target exercises the intrinsics.

## Algorithm

```
step = STEP[idx]; diff = step>>3
if n&4: diff+=step ; if n&2: diff+=step>>1 ; if n&1: diff+=step>>2
pred = (n&8) ? sub_sat(pred,diff) : add_sat(pred,diff)   # G_SSUBSAT / G_SADDSAT
idx += IDX[n]; clamp idx to [0,88]                        # LUT walk
GATE_N nibbles from a PRNG; fold the predictor stream (serial recurrence).
```
