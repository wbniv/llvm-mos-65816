Fold bounded native far word loads in speed-optimized functions

Admit plain two-byte far loads to the all-users indexed-address walk.
Require the final byte of every sibling to fit Y8; reject atomic,
escaping, call-separated, and unsupported uses. Reuse the original
bounded offset expression and existing M16/Y8 pseudo.

Extend far-index-fold-debug.ll with a -g word fold: the fold drops
the dead pointer's debug location through the same path as the byte
fold.

Default to speed at O2/O3, excluding optsize/minsize/optnone. Retain
hidden off/all controls for experiments; all ignores size attributes and
the -O level but, like every policy, never folds in an optnone function
(independent review N5). The downstream evidence and
its size tradeoffs are retained in the far-word-index preparation packet;
they are not measurements of this rebased compiler.
